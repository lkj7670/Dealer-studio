✨ AI 정밀 스캔 설정 (Gemini)

    

      
키를 넣으면 사진을 Gemini Flash가 읽어 표를 정확하게 뽑습니다. 어떤 모델을 쓸 수 있는지는 앱이 키로 직접 확인해 가장 빠른 모델을 스스로 고릅니다. 키가 없으면 폰 안에서 도는 기본 인식만 쓰고, 그때는 인터넷 없이도 됩니다.

      
      

        
        
        
      

      
키를 넣으면 사진은 항상 AI(Gemini)로 먼저 읽고, 인터넷·키가 없을 때만 폰 안 인식으로 넘어갑니다.

      

      

        키 발급: aistudio.google.com/apikey (구글 계정 · 무료) → Flash 모델 기준 하루 약 500건 무료.

        무료 등급은 올린 사진이 구글 모델 학습에 쓰일 수 있습니다. 키는 이 폰 저장소(localStorage)에만 저장되고 폰 밖으로 나가지 않아요.
      

    

    

  







  

    
📱 바탕화면 아이콘 추가 방법

    

      

        
        
물류 현장

        
이 아이콘과 이름이 홈 화면에 생깁니다.

      

      

        1. 안드로이드 크롬 (현장 폰)
        
브라우저 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치) → 이름이 물류 현장인지 확인 → 추가.
카톡으로 받은 파일은 먼저 다운로드 폴더에 저장한 뒤 Chrome으로 열어야 합니다.

      

      

        2. 아이폰 사파리
        
아래 공유 버튼 → 홈 화면에 추가 → 추가.

      

      

        3. 아이콘이 기본 모양으로 나올 때
        
파일(file://)로 바로 열면 브라우저에 따라 홈 화면 추가가 안 보이거나 아이콘이 기본 모양일 수 있습니다. 이때는 웹 주소(https)로 올려서 열면 내장된 아이콘·이름(물류 현장)이 그대로 나옵니다. site.zip 안에 manifest와 아이콘 파일이 같이 들어 있습니다.

      

      

        4. 한 번 열어 두면
        
홈 화면 아이콘으로 열면 주소창이 없는 앱 화면으로 뜨고, 오늘 목록·기준표는 폰에 저장된 그대로 이어집니다.

      

      
🔐 회사 내부 자료입니다. 웹 주소로 올릴 때는 비밀번호·접근 제한이 있는 곳에만 올리고, 현장 PIN을 켜 두세요.
